# Pitch de 3 minutos

- `quorum-pitch.pdf`: las 6 diapositivas (1920×1080).
- `quorum-pitch.html`: la misma versión en HTML, para abrir en el navegador.
- `guion.md`: lo que se dice en cada diapositiva, con los tiempos (unos 2:50 en total).
- `fuente/`: los archivos del deck de Claude Artifacts.
- `fuente/armar.py`: rearma el HTML y el guion. Uso: `python3 fuente/armar.py <carpeta con project/> <salida>`. El PDF sale del HTML impreso con Chrome sin cabecera.

Orden: vector de riesgo, mecanismo defensivo, validación empírica (dos diapositivas), límites y riesgo dual. Las cifras salen de `docs/documento-tecnico/quorum.tex`.

Según el reglamento, el pitch proyecta la ficha técnica. Si es así, estas diapositivas sirven de guion y de respaldo.
